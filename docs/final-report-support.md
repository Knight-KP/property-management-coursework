# Final Report Support

## Project Summary
This project is a Property Management System developed as a console application. It manages tenants, complaints, maintenance jobs, and invoices.

## System Highlights
- Layered architecture for better structure
- Role-based team development
- Clear separation of concerns
- Integration between complaint, maintenance, and billing workflows

## Team Contribution
Each team member contributed to a specific module while maintaining understanding of the full system.

## Development Approach
- Modular development
- Regular commits for tracking progress
- Documentation alongside development
- Testing performed before code freeze

## Final Status
- Code freeze completed on 5 April
